MAU ID 发布

我们发布了 MAU ID — 我们在 MAU Accounts DAO 生态系统中的身份识别和认证系统

发布于 26 六月 2025 作者 MAU Accounts DAO

MAU ID 身份识别 认证 生态系统 去中心化

0 分钟阅读

我们发布了 MAU ID — 我们在 MAU Accounts DAO 生态系统中的身份识别和认证系统。

这个项目并非试图发明另一个”新互联网”。相反，它是对近年来数字身份日益演变趋势的冷静而深思熟虑的回应。越来越多地，人们被提供同样的模式：一个中心化的提供商，一个”万能”的密钥，大规模的数据收集，以及用户对自己数字身份控制权的逐渐丧失。

MAU ID 建立在不同的原则之上。

我们有意不走超级中心化的道路，也不打算成为面向所有人的通用身份提供商。MAU ID 是一个自主的、面向网络的模式的一部分，在这个模式中，身份仍然是用户的工具，而不是外部控制的杠杆。这不是协议层面或区块链驱动的去中心化。这是另一种去中心化——组织性和价值观驱动的——通过系统架构、访问规则和数据处理方式来体现。

从实用角度来看，MAU ID 解决的是非常实际的需求。用户可以注册、登录生态系统服务，并使用熟悉易懂的机制管理他们的会话和认证方法——用户名、密码和现代访问密钥。无需生物识别数据。不依赖全球身份垄断企业。没有隐藏条件。

在底层，MAU ID 建立在一个成熟的、工业级的、开放的解决方案之上，这个方案经过了时间和实际使用的验证。我们有意选择可靠性而非实验性，因为身份不是技术冒险主义的领域。它是建立信任的基础。

从更广泛的意义上说，MAU ID 可以被视为 Web 2.0 和 Web 3.0 之间的桥梁之一。它允许人们生活在熟悉的网络中，使用普通的网站和服务，同时逐渐远离完全外部控制的模式，转向更加自主的、以用户为导向的系统。

重要的是要强调，MAU ID 不仅仅是为我们的内部项目设计的。我们愿意将其提供给希望在自己的网站、应用程序和服务中使用 MAU ID 的社区成员和独立项目，作为安全、全面、可管理的身份和访问管理的现成基础。

使用 MAU ID，您可以：

  • 使用不绑定全球公司的独立标识符，
  • 受益于成熟的、生产级的系统，而无需自己构建和维护复杂的基础设施，
  • 保留对访问规则、安全策略和用户账户生命周期的控制权。

MAU ID 已在 MAU Accounts DAO 生态系统中投入使用，并将作为未来服务和项目的基础。我们继续谨慎地、不急不躁地开发它——按照猫咪们喜欢的方式：先稳定，后扩展。
